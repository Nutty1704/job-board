# Job Board

Greenfield personal job board that aggregates jobs from multiple sources, stores job details and embeddings, scores matches against a personal profile, and pre-generates optimized resumes for high-fit roles.

## Repository structure

- `apps`: deployable applications and workers as they are introduced.
- `packages`: shared libraries as they are introduced.
- `infra`: infrastructure code as it is introduced.
- `docs`: architecture notes and decisions.
- `scripts`: development and deployment helpers.
